Kelola Kode Akses

Tulis semua kode yang boleh masuk, satu kode per baris. Kode yang tidak ada di daftar ini tidak bisa lagi dipakai masuk. Huruf besar dan kecil dianggap sama.

File ini berisi kunci rahasia aplikasi. Simpan untuk Anda sendiri, jangan dibagikan atau diunggah ke GitHub.

  1. Klik tombol di atas. File kunci.json akan terunduh.
  2. Buka halaman unggah GitHub, seret file kunci.json ke sana, lalu klik Commit changes.
  3. Tunggu sekitar 1 sampai 2 menit. Kode baru langsung berlaku di web.
